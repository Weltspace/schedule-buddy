# 📅 日程助手 Schedule Buddy

[English](README.md) | **简体中文**

一个单机、零配置、不上传任何数据的**本地日程安排工具**。三种形态，同一套体验：**Windows 桌面软件**（双击打开独立窗口）、**安卓 APP**（安装包直接装）、**手机网页版**（浏览器即开即用）。日程、长期目标、统计数据全部存在你自己的设备上。

## ✨ 功能一览

- **AI 助手**：用一句话安排任务（“明天下午3点开会”“接下来两周每天背30分钟单词”），AI 自动解析时间并直接创建/修改日程和长期任务，可以多轮对话补充细节
- **AI 分析**：周 / 月 / 长期三种视角，点「开始分析」才调用 AI（平时零消耗），给出完成热力图、完成率圆环、图表、洞察和建议，还能继续追问
- **桌面窗口**：独立窗口运行（pywebview），点 × 最小化到托盘，提醒照常弹，托盘右键才真正退出
- **安卓 APP**：真正的独立安装包（约 2MB）——独立图标、全屏运行、完全离线，数据存 APP 私有空间；导出同步包直发微信，微信收到的同步包一键导入
- **日程管理**：新建 / 编辑 / 删除 / 标记完成，界面保持极简（优先级、分类等标签体系已移除）
- **提醒**：可设提前 5 分钟～1 天提醒，到点弹 Windows 系统通知 + 窗口内提示；错过超过 10 分钟的过期提醒不再补弹
- **长期任务**：立长期目标，项目和每个子任务都可以带截止日期（显示"剩 N 天"，过期标红）；任务和子任务都能拖拽排序，进度条自动计算
- **统计与报告**：完成率、本月热力图、分类占比，外加可翻周的**周报**和**总报告**（近 6 个月趋势、最常完成的日子、对比上周）
- **换背景 / 换图标**：设置里拖一张图进去，界面背景、标题栏、任务栏、托盘、桌面快捷方式、开始菜单的图标全部同步更换，一键恢复默认
- **中英界面**：右上角 ⚙ 设置里一键切换中文 / English（日程内容保持原样）
- **界面透明度**：设了背景图之后，卡片透明度可以在设置里随意调
- **数据在本地**：就是你自己电脑上的几个文件，复制走就是备份

## 🚀 快速上手（电脑小白照着一步步做就行）

> 需要：Windows 10 / 11 电脑。全程不需要敲命令，只有一步要复制粘贴。
>
> **最省事的方式**：直接从上面 [Releases](https://github.com/Weltspace/schedule-buddy/releases/latest) 下载 `windows-portable.zip`，解压后跳到"第 4 步：启动"。
>
> **先看一眼文件夹里有没有 `runtime` 文件夹：**
> - **有 `runtime`**（朋友直接拷给你的、或发布压缩包里带的）：什么都不用装，**直接跳到第 3 步启动**！
> - **没有 `runtime`**（从 GitHub 下载的源码包）：按第 1、2 步装好 Python 和依赖即可

### 第 1 步：安装 Python（文件夹里已有 runtime 就跳过第 1、2 步）

1. 打开 [https://www.python.org/downloads/](https://www.python.org/downloads/)，点击黄色的 **Download Python 3.x.x** 按钮下载
2. 双击运行下载的安装包，**第一个界面务必勾选底部的 "Add Python to PATH"**，再点 **Install Now**
3. 装完即可（不用管 Python 自带的那个黑色窗口）

> ⚠️ 忘了勾 "Add Python to PATH" 是小白最常见的翻车原因。如果已经装错了，重新运行安装包选 Modify 修复，或者卸载重装一次。

### 第 2 步：下载本软件

1. 回到本页面，点右上角绿色 **Code** 按钮 → **Download ZIP**
2. 找到下载的 `schedule-buddy-main.zip`，右键 → **全部解压**（不要直接在压缩包里双击运行！）
3. 解压后你会得到一个 `schedule-buddy-main` 文件夹，把它放到你喜欢的位置（比如 D 盘），**以后别随便挪动它**

> 会用 Git 的也可以：`git clone https://github.com/Weltspace/schedule-buddy.git`

### 第 3 步：安装依赖（双击一个文件，只需一次；文件夹里已有 runtime 就跳过）

打开解压出来的文件夹，**双击 `install_requirements.bat`**，等它显示"安装完成"（需要联网，约 1～3 分钟）。这一步是把运行需要的组件装好，以后不用再做。

### 第 4 步：启动！

**双击 `start_schedule_buddy.vbs`**——日程助手窗口就会弹出来，开始用吧！

> 文件夹里有 `runtime` 的话，这里是全部步骤：它自带了完整的运行环境（Python 和全部依赖库），**不需要安装 Python，也不需要管理员权限**。

- 窗口右上角 ⚙ 是设置（语言 / 背景 / 图标 / 透明度）
- 点窗口的 × 只是收到托盘，提醒照常工作；**彻底退出**请右键屏幕右下角托盘图标 → 退出
- 想开机自动启动？把 `start_schedule_buddy.vbs` 的快捷方式放进启动文件夹（`Win+R` 输入 `shell:startup` 回车，把快捷方式丢进去）

### 第 5 步（推荐）：创建带图标的桌面快捷方式

双击 `create_desktop_shortcut.py`，它会在桌面创建一个带日历图标的「日程助手」快捷方式，以后从桌面双击就能启动。（程序每次启动也会自动创建/修复这个快捷方式；文件夹里有 `runtime` 且没装 Python 的电脑上，直接启动一次程序即可，跳过本步。）

> 📌 以后每次想用：双击桌面上的「日程助手」或文件夹里的 `start_schedule_buddy.vbs` 就行。程序已在运行时再次双击，会直接把窗口调出来。

## 🖥️ 界面说明

- **今天 / 本周**：按天、按周查看和安排日程；顶部可隐藏已完成
- **统计**：完成率、本月热力图、分类占比
- **周报 / 总报告**：统计页往下滚——周报可翻看任意一周（按天完成情况、对比上周）；总报告是全部数据汇总（近 6 个月趋势、最常完成的日子）
- **长期任务**：顶栏第 4 个标签页。输入目标（可选截止日期）→ 添加；每个子任务也能设截止日期（行内"📅 截止日期"按钮）；任务卡片和子任务都可以**直接拖动**调整顺序；勾选子任务，进度条自动涨

## 🎨 换背景 / 换图标（好玩的）

点右上角齿轮 ⚙ 打开设置：

- **背景图片**：拖一张图进虚线框，界面背景立刻更换；下面的透明度滑块可以调卡片虚实；"恢复默认背景"一键还原
- **软件图标**：拖一张图（建议 256×256 以上，会自动裁方）——**标题栏、任务栏、托盘、桌面快捷方式、开始菜单**的图标全部换成你的图，"恢复默认图标"一键还原

也可以把图片文件直接拖到 `change_icon.py` 上，只换图标不动背景。

## 📱 手机版（安卓 APP / 网页 PWA，与电脑数据互通）

手机端有三种用法，日程数据都存在手机本地（AI 同样是设备直连智谱 GLM）：

### 方式一：安卓 APP（推荐，体验最完整）

真正的独立安装包——桌面图标、全屏运行、没有浏览器界面、完全离线可用，**数据存在 APP 私有空间**（不寄存在浏览器里，系统清不掉）：

1. 到 [Releases](https://github.com/Weltspace/schedule-buddy/releases) 下载最新的 `ScheduleBuddy-vX.X.apk`，微信/QQ 发到手机后点开安装（提示"未知来源应用"属安卓对商店外安装的正常提醒，允许即可）
2. 打开 APP，到 ⚙ 设置里填入你的智谱 API Key 即可使用全部功能
3. 同步包体验是原生的：点「导出同步包」直接弹**系统分享面板**（选微信发给文件传输助手）；微信里收到同步包，点开 → 右上角"…" → **用其他应用打开 → 日程助手**，确认后一键导入，全程不用离开微信

自己打包：在电脑上运行 `./runtime/python.exe make_apk.py`（需要 JDK / Android SDK / Gradle 打包环境，一次性装好后写在 `E:\android-build` 即可，详见 `make_apk.py` 文件头说明）。以后每次更新了代码重新打包，发到手机**覆盖安装**即可，数据不会丢。

### 方式二：网页版（PWA，浏览器即开即用）

1. 在电脑上运行 `python deploy_pages.py`（需先 git init 并添加 GitHub 远程仓库），把网页发布到 GitHub Pages；也可以在 GitHub 网页端手动上传 `index.html`、`manifest.json`、`sw.js` 和 `static/` 文件夹
2. 仓库 Settings → Pages 选择 gh-pages 分支开启，手机浏览器访问 `https://<用户名>.github.io/<仓库名>/`
3. 到 ⚙ 设置里填入你的智谱 API Key
4. 想装得像个 App：打开 ⚙ 设置里的「安装到桌面」点一下（Chrome / Edge 会装成独立应用）；国产浏览器没弹出安装框的话，用浏览器菜单里的「添加到主屏幕 / 添加到桌面」——多数国产浏览器只生成书签快捷方式，想要真 App 请用方式一

### 方式三：局域网访问电脑版

见下文「📶 让手机访问电脑版」。

**数据互通（手动同步包，适合电脑不常开的情况）：**

数据不实时同步，而是像传文件一样：在 ⚙ 设置 →「数据同步」里**导出同步包**（一个 json 文件），通过微信文件传输助手等任意方式发给另一台设备，在那边**导入同步包**即可（整体覆盖）。安卓 APP 里更直接：导出弹系统分享面板直发微信；微信收到的包"用其他应用打开 → 日程助手"一键导入。导入时如果本地有没同步过的修改，会先提醒你再覆盖。同步内容是全部日程和长期任务；背景图、语言等各自设备独立。

> 注意：手机数据存在设备本地（APP 私有空间或浏览器 IndexedDB），请勿清除 APP 数据/浏览器数据；恢复出厂/换机前先导出一份同步包。

## 📶 让手机访问电脑版（可选，默认关闭）


程序默认只监听本机（安全默认值，服务没有登录功能）。在可信的家庭 Wi-Fi 里想让手机用一下：

1. 彻底退出程序
2. 打开命令提示符（`Win+R` 输入 `cmd` 回车），执行：
   ```
   set SCHEDULE_BUDDY_LAN=1
   python app.py
   ```
3. 手机浏览器访问 `http://电脑IP:5217`（电脑 IP 用 `ipconfig` 命令查看）

## 🤖 AI 功能（可选）

AI 助手和 AI 分析默认关闭：到 ⚙ 设置里粘贴一个[智谱开放平台](https://open.bigmodel.cn/)的 API Key 即可开启（默认 `glm-4.7-flash` 免费，限流时可换备用免费的 `glm-4.5-flash`；`glm-5.3-flash` 更强但计费，需要更好的分析质量时在设置里切换。Key 只保存在你电脑的 `data/settings.json` 里，不会上传）。

- **AI 助手**：对话式安排，支持一次性创建多个日程、改期、查询、添加长期任务和子任务
- **AI 分析**：分**周分析 / 月分析 / 长期分析**三种视角（热力图、完成率、进度条、截止提醒），本地先聚合好数据，点「开始分析」才调用一次 AI；分析完可以继续追问，追问复用刚才的数据，不重复消耗

不用 AI 功能完全不影响软件的其他部分。

## 💾 数据与备份

所有数据都在 `data` 文件夹里：`schedule.json`（日程和长期任务）、`settings.json`（设置）。**备份 = 复制 `data` 文件夹**；恢复 = 放回去。文件损坏程序也不会挂（自动把坏文件改名备份后从空白开始），但重要数据请勤备份。

## ❓ 常见问题

**需要管理员权限吗？**
不需要。程序只在自己文件夹、桌面和开始菜单（都是你的用户目录）里读写文件，代码里没有任何申请管理员权限的逻辑。首次运行如果弹出蓝色提示"Windows 已保护你的电脑"，那是 SmartScreen 对网上下载文件的例行提醒，点"更多信息 → 仍要运行"即可，与管理员权限无关。

**双击 .bat 或 .py 文件一闪而过 / 提示 "python 不是内部或外部命令"？**
Python 没装好或没勾 "Add Python to PATH"。重装 Python 并勾选，然后重新运行 `install_requirements.bat`。

**双击 vbs 没反应？**
等 2～3 秒窗口才会出现。如果任务栏有图标但窗口没出来，点一下任务栏图标即可。还是不行就双击 `start_schedule_buddy_console.bat`，黑窗口里会显示具体报错信息。

**提示端口被占用？**
说明程序已经在运行了，再双击一次会把窗口调出来。想换端口：命令行里 `set SCHEDULE_BUDDY_PORT=8080` 后再运行 `python app.py`。

**收不到系统通知？**
Windows 设置 → 系统 → 通知，确认"日程助手"（python.exe）的通知没有被关闭。

**怎么彻底退出？**
右键托盘图标 → 退出。关窗口只是最小化到托盘。

**换电脑 / 移动文件夹后快捷方式失效？**
整个文件夹随便搬，数据跟着走。到新位置双击一次 `create_desktop_shortcut.py` 即可；或者直接启动一次程序，它会自动修好桌面快捷方式。

**杀毒软件报毒？**
本软件是纯 Python 脚本，无任何联网上传行为，可放心加入白名单（个别杀软对 vbs/脚本类启动方式比较敏感）。

**手机 APP 安装时提示"未知来源/禁止安装"？**
安卓对应用商店之外安装包的正常提示。在系统弹窗里点"仍然安装/允许"，或在系统设置里给微信/文件管理器开通"安装未知应用"权限。

**手机 APP 里点"导出同步包 / 背景图片 / 导入同步包"没反应？**
升级到 v1.1 或更新的 APK（旧版在 WebView 里没接文件选择器和分享面板）。导出后弹出的是系统分享面板，需要在面板里选一个目标（如微信）才算完成。

**手机 APP 怎么更新？**
新版本 APK 覆盖安装即可，数据不会丢（同一个签名密钥）。网页版则是打开即最新，无需任何操作。

## ⚙️ 常用环境变量（可选进阶）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `SCHEDULE_BUDDY_PORT` | `5217` | 服务端口 |
| `SCHEDULE_BUDDY_LAN` | 不开 | 设为 `1` 监听局域网（见上文手机访问） |

## 📁 项目结构

```
├── AGENTS.md                     # 给 AI 编程助手的项目说明书（架构/约定/坑）
├── app.py                        # 主程序：Flask API、桌面窗口、系统托盘、AUMID
├── ai.py                         # AI 功能：GLM 工具调用助手、统计分析
├── storage.py                    # 数据层：日程/长期任务/设置/报表/同步包，原子写入
├── media.py                      # 背景图保存、图标生成、任务栏图标(AUMID)、快捷方式
├── notifier.py                   # Windows 系统通知封装
├── make_icon.py                  # 默认图标生成脚本（可改配色重新生成）
├── make_pwa_icons.py             # 从 icon.ico 生成 PWA 用 PNG 图标
├── change_icon.py                # 手动换图标：拖图片上去即可
├── create_desktop_shortcut.py    # 创建桌面快捷方式
├── deploy_pages.py               # 把网页版发布到 GitHub Pages（gh-pages 分支）
├── make_apk.py                   # 一键打包安卓 APK（拷前端→Gradle→签名→输出 dist/）
├── make_zip.py                   # 一键打包 Windows 便携 zip（解压即用，挂 Release 用）
├── android/                      # 安卓壳工程：WebView 离线壳 + 微信分享/导入原生桥
├── dist/                         # 打包产物（ScheduleBuddy-vX.X.apk，不入库）
├── start_schedule_buddy.vbs      # 日常启动入口（无黑窗口；优先用 runtime）
├── start_schedule_buddy_console.bat  # 带控制台的启动（看日志排错用）
├── install_requirements.bat      # 无 runtime 时安装依赖（双击即可）
├── index.html                    # 整个 UI 的唯一 HTML（电脑/手机共用）
├── manifest.json + sw.js         # PWA：手机"添加到主屏幕"与离线缓存
├── runtime/                      # 自带便携运行环境：Python 3.12 + 全部依赖库
├── requirements.txt              # 依赖清单（供 pip 安装/升级用）
├── static/api.js                 # 前端数据入口：电脑走 Flask / 手机走本地实现
├── static/local/storage.js       # 手机版本地数据层（IndexedDB，storage.py 的移植）
├── static/local/ai.js            # 手机版本地 AI（浏览器直连 GLM，ai.py 的移植）
├── static/main.js + style.css    # 前端逻辑与样式（含 i18n 词典、移动端适配）
└── data/                         # 你的数据（schedule.json / settings.json）
```

- **直接打包发人**：把整个文件夹压缩成 zip 发出去即可——只要对方是 Windows 10/11，解压后双击 `start_schedule_buddy.vbs` 就能用，**对方连 Python 都不用装**。也可以直接发 Releases 里的 `windows-portable.zip`；自己想重新打一个：`./runtime/python.exe make_zip.py`
- **把 APK 挂到 GitHub Releases**：`make_apk.py` 的产物在 `dist/`，把 `ScheduleBuddy-vX.X.apk` 传到 Release，安卓用户不装任何打包工具就能直接装 App。
- **用 Git 托管源码**：`runtime/` 体积大（约 50MB 的二进制），不建议提交进仓库（.gitignore 已排除）。从 Git 克隆的用户按"快速上手"装一次 Python 并双击 `install_requirements.bat` 即可；或把含 runtime 的 zip 挂在 GitHub Releases 供下载。

## 🔧 技术说明

- **运行形态**：pywebview 桌面窗口（点 × 隐藏到托盘常驻）；未安装 pywebview 时自动回退浏览器模式
- **安卓壳**：WebView 离线壳，前端整体打进 APK，经 WebViewAssetLoader 以正规 https origin 加载（IndexedDB 在 file:// 不可靠）；原生桥负责文件选择器（换背景/导入）、系统分享面板（导出）、微信"用其他应用打开"（一键导入）；APK 内不注册 Service Worker（前端已内置，避免升级后吃到旧缓存）
- **任务栏图标**：通过显式 AppUserModelID + 带相同 AUMID 的开始菜单快捷方式实现，换图标时全部图标位置同步更新
- **提醒链路**：后台线程每 30 秒扫描到期日程弹系统通知，窗口内同步弹提示；共享"已提醒"标记不会重复弹；过期超 10 分钟静默跳过
- **数据安全**：每次修改原子落盘（临时文件 + 替换），损坏自恢复；所有请求有 CSRF 防护
